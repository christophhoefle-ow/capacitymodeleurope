# Data sources: what is used, what is available

| Source | Content | Licence and access | Use in the model |
|---|---|---|---|
| JAO Publication Tool, Final Computation | hourly flows and limits per network element, all 16 Core TSOs | public API | utilization (automatic, daily) |
| JAO Core Static Grid Model (SGM), release 202603 | lines, tie-lines, transformers of all 16 Core TSOs with technical data (Imax, impedances, length), released twice a year | public download on jao.eu/static-grid-model | the master data of the model (`scripts/ingest_sgm.py`) |
| TenneT static grid model (03/2025) | the same structure with longitude and latitude of the TenneT Germany substations | published by the TSO | exact positions of 172 substations (`data/static/coordinates_tennet_sgm_03_2025.csv`) |
| 50Hertz static grid model (Q4 2025) | the 50Hertz network with ENTSO-E node codes, no coordinates | published by the TSO | cross-check only: same network as in the Core SGM |
| BNetzA netzausbau.de | German transmission projects (BBPlG) with status and built kilometres per section | public web pages | `data/static/grid_expansion_*.csv`, maintained by hand with source and date |
| ENTSO-E TYNDP 2024 | 177 transmission and 33 storage projects of all ENTSO-E members with promoters, countries, status, commissioning year and capacity; six Regional Investment Plans with links to the national plans | CC BY 4.0, project sheets online, open copy as zip | backbone of the European expansion layer; structure check: workflow Check TYNDP project data |
| EU Union list of PCI and PMI (second list, adopted 04/2026) | 235 cross-border projects, 113 of them electricity, offshore and smart grids; the EC keeps an interactive map | public, Delegated Regulation (EU) 2026/764 | flag for projects of common interest, cross-border scope |
| National plans (Elia, TenneT NL, RTE, PSE, APG, CEPS, MAVIR, Transelectrica, SEPS, ELES, HOPS) | internal reinforcements and details per project | public web pages, formats differ | detail for the projects, maintained by hand with source and date |
| ENTSO-E Transparency Platform, item 9.1 | changes to network elements and interconnector projects within three years | official, API with token | no data on the API yet (as of 03/2026): to be checked again |
| DLR, Georeferentiation of CORE-TSO substations with OSM (Zenodo 10.5281/zenodo.13367535) | substations, transformers and lines of the Core TSOs of 13 countries matched with OpenStreetMap, with coordinates | ODbL, download by Zenodo link, version 0.2 (08/2024) | in use: exact substation positions, automatic (`scripts/update_geodata.py`, action Update map geodata). Bundled until the first run: an excerpt for AT, BE, CZ, DE and part of FR |
| PyPSA-Eur prebuilt OSM network (Zenodo 10.5281/zenodo.18619025, retrieved 11.02.2026) | European grid 220 to 750 kV from OpenStreetMap incl. DC links and under-construction objects | ODbL, download by Zenodo link | candidate for the background network and for projects under construction |
| OpenStreetMap (Overpass API) | substations and lines with names, voltage, operator and coordinates | ODbL, free API with fair-use limits | fallback for exact positions of single substations |
| Natural Earth, admin 0 countries 1:50m | country borders | public domain, GeoJSON on GitHub (nvkelso/natural-earth-vector) | automatic (`scripts/update_geodata.py`), simplified to about 4,500 points; until the first run the map uses hand-drawn outlines (`src/capmodel/xl/outline.py`). Eurostat GISCO was not chosen: its boundaries may not be used commercially |
| Capacitypedia (ENTSO-E and DSO Entity, launched 05/2026), https://www.tsodsoplatform.eu/capacitypedia | directory of the hosting-capacity publications: one page per operator with status, link, format, interface, update cycle | public | automatic, weekly: register of all Core TSOs in `data/processed/connection_publications.csv`. Listed 11/2026: 50Hertz, Amprion, TenneT, TransnetBW, APG, CEPS, Creos, ELES, Elia, PSE, SEPS, TenneT NL; not listed: RTE, MAVIR, HOPS, Transelectrica |
| 50Hertz, substations with connection perspective (PDF on https://www.50hertz.com/de/Vertragspartner/Netzkunden/Netzanschluss) | per substation: switch-bay availability in words, feed-in and load capacity as MW classes (cell colours); unlisted substations offer no connection at present | public, no interface, updated when needed | automatic, weekly (`scripts/fetch_connection_capacity.py`): status proven on the file of 24.08.2025, MW classes read if the legend colours can be matched |
| TransnetBW, Netzanschlusskarte (https://www.transnetbw.de/de/transparenz/netzzugang-und-entgelt/netzanschlusskarte) | per substation: status (mittelfristig, langfristig, nicht verfügbar), earliest year, feed-in and load capacity as MW classes, all as text | public, no interface, updated cyclically | automatic, weekly (adapter `page_blocks`): checked on the real page content of 25.11.2026 (52 substations, as of 01.04.2026) |
| Amprion, Ergänzendes Dokument zu potenziellen Netzanschlussmöglichkeiten (PDF on https://www.amprion.net/Strommarkt/Netzkunden/Netzanschluss/) | the substations where a connection is expected to be feasible: voltage, (n-0)/(n-1), earliest year, remark; the map with its second category (red, no connection possible) is not read | public, no interface, static (April 2026) | automatic, weekly (adapter `pdf_rows`): checked on the real text of the file (10 substations) |
| TenneT, Netzanschlussanfragen (https://www.tennet.eu/de/strommarkt/kunden-deutschland/netzanschlussanfragen) | table of sites with possible connections in the current round, with indicative coordinates | public, no interface; the page turned away automatic requests on 25.11.2026 | adapter `table` with a browser, not verified on the real page |

Legal basis of the connection publications: Regulation (EU) 2019/943, Article 50(4a) (TSOs: per substation, updated at least monthly).

## Assessment
* Coverage today: the network of all 13 countries is complete (Static Grid Model). The utilization data cover only the elements JAO publishes (about 860 in the test hour).
* Positions: with the bundled excerpt 825 of 1,441 Core substations are exact (Germany 380 of 403); after the first run of Update map geodata all substations of the DLR table are.
* The TenneT file is rounded to about 1 km and unreliable for substations of other operators (up to 81 km off): OpenStreetMap ranks above it.
* All three can be automated: SGM and Zenodo files are downloaded by link (twice a year is enough), the result is committed as static CSV files.
* Attribution: OpenStreetMap-based data need "© OpenStreetMap contributors" and stay under ODbL.
